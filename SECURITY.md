# Security

Please don't report a vulnerability in a public issue.

Report it privately through
[GitHub's security advisories](https://github.com/respanai/respan-gateway/security/advisories/new),
or email security@respan.ai. Include what you found, how to reproduce it,
and the version (`respan-gateway --version`).

We reply within three business days, and credit you in the release that
fixes it unless you'd rather we didn't.

Fixes go into the latest release. Older releases don't receive patches.
